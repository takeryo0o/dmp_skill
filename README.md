# 追加能力ジェネレーター

GitHub Pages用・フォルダ分けなし版です。

## 今回の仕様

- NORMAL：通常能力から抽選
- RARE：強力な能力から抽選
- EPIC：以前作成した100種類の特殊能力から抽選
- NORMAL / RARE：条件と能力を別々にランダム抽選し、使用回数は1～6回
- EPIC：以前のコードに設定されていた「能力と専用条件」の組み合わせを維持
- EPICの使用回数・制限も旧条件をもとに表示

## 能力ストック

生成結果の「ストック」ボタンを押すと、ページ下部の能力ストックへ追加されます。

ストック内容はブラウザの `localStorage` に保存されるため、

- ページ再読み込み
- ブラウザを閉じて再度開く
- GitHub Pages上のファイルを更新する

といった場合でも、同じブラウザ・同じサイトデータが残っていれば保持されます。

ブラウザのサイトデータを削除した場合、シークレットモード、別ブラウザ・別端末では引き継がれません。

## NORMAL / RARE 発動回数の確率

`generator.js` の `randomActivationCount()` で設定しています。

初期値：

- 1回：5%
- 2回：10%
- 3回：25%
- 4回：30%
- 5回：25%
- 6回：5%

合計100%です。

## スキル使用回数カウンター

ストックした能力には「使用する」ボタンが表示されます。

ボタンを押すと「スキルを使用しますか？」と確認され、
OKを押すと使用回数が記録されます。

例：

- 初期：`使用 0/3`
- 1回使用：`使用 1/3`
- 2回使用：`使用 2/3`
- 3回使用：`使用 3/3`

上限に達すると「使用済み」となり、それ以上押せなくなります。

「常時」「1ターンに1回」など、ゲーム全体での固定上限がない能力は、
`使用 1回`、`使用 2回` のように累計使用回数だけ記録します。

使用回数もストック情報と同じくブラウザの `localStorage` に保存されます。


## NORMAL能力を100種類に拡張

`normalSkills.js` を N001 ～ N100 の100種類にしました。
N031 ～ N100 は、ドロー・墓地・マナ・タップ・除去・バウンス・
パワー操作・コスト軽減・キーワード能力付与などを中心に追加しています。
